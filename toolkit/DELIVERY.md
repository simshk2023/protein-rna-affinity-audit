# Calling the evaluation toolkit

The evaluation core, CLI, input schema and synthetic example live here. Run the release-level `python -B reproduce.py smoke --output ../synthetic_smoke` from the package root to check the example and tests. For the primary reported results, use the package-level `primary` command and the frozen input manifest. The toolkit expects curated members, correspondence and aligned inputs as described in [SCHEMA.md](SCHEMA.md).
