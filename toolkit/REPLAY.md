# Real-data replay

Run the package-level `reproduce.py primary` route for the reported controlled CoPRA and additive results. It uses the frozen provider snapshot and OOF endpoint predictions, the shipped source links and family folds, and the verified current exclusions. For method-specific statistics from archived predictions use `reproduce.py full`. Keep emitted real-data inputs and results in private storage.
